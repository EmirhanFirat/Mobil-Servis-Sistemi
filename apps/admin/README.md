# TalepAkış — yönetici paneli

React 19 + Vite 8 + TypeScript. Yalnızca yönetici rolüne açıktır: talep listesi ve ayrıntısı, ekip/görevli ataması, öncelik–kategori–eksik bilgi düzeltme, kullanıcı ve ekip üyeliği yönetimi.

```powershell
npm install
npm run dev          # http://localhost:5173 (API: VITE_API_URL, varsayılan http://127.0.0.1:8000)
npm test             # Vitest
npm run typecheck
npm run lint         # oxlint
npm run build
```

Kurulum, demo hesabı ve API'nin CORS ayarı için kök [README](../../README.md); tasarım kararları için [docs/DECISIONS.md](../../docs/DECISIONS.md) (D18).
